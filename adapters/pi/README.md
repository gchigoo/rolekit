# RoleKit adapter — Pi

## Install

Copy target: `%USERPROFILE%\.pi\agent\skills\rolekit-adapter-pi\SKILL.md`

```
npm run install-skill:pi
```

Or:

```
mkdir "%USERPROFILE%\.pi\agent\skills\rolekit-adapter-pi"
cp adapters/pi/SKILL.md "%USERPROFILE%\.pi\agent\skills\rolekit-adapter-pi\SKILL.md"
```

Requires `rolekit` on PATH. Regenerated products come from `adapters/shared/command-map.md` via `npm run build:adapters`.
