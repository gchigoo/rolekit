# RoleKit adapter — Cursor

## Install

Copy target (repo-local): `.cursor/skills/rolekit-adapter-cursor/SKILL.md`

```
npm run install-skill:cursor
```

Or:

```
mkdir .cursor/skills/rolekit-adapter-cursor
cp adapters/cursor/SKILL.md .cursor/skills/rolekit-adapter-cursor/SKILL.md
```

Requires `rolekit` on PATH. Regenerated products come from `adapters/shared/command-map.md` via `npm run build:adapters`.
